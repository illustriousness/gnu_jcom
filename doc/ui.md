
# qml ui设计需求
## 定义
- 顶栏常驻显示:协议解析 文件传输 终端模式 串口设置 
- 左侧栏 可隐藏
- 主界面 除了顶栏和左侧栏外的位置

左侧栏和用户界面跟随顶栏切换

## 配色和其他
- 参考vsc的现代深色主题和布局风格 
- 美观优先
- 只动qml
